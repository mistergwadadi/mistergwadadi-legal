MisterGwadadi — Content Automation

Privacy Policy

Last updated: September 24, 2026

In one sentence: this is a personal, single-user tool that generates short videos and publishes them to the developer's own TikTok account — it does not collect, store, or share data belonging to any other person.

1. Who operates this tool

This application is built and operated by an individual creator (TikTok handle @joachime97, displayed as MisterGwadadi) for personal use only. It is not offered as a service to other users, and no other TikTok account can authorize or use it.

2. What the tool does

The tool automatically generates short vertical videos on a daily schedule — for example a daily horoscope, video game release highlights, and trending manga rankings — and publishes them to the developer's own TikTok account through TikTok's Content Posting API.

3. Data accessed via TikTok

The only TikTok data this tool accesses is:

  • The developer's own OAuth access token and Open ID, obtained when the developer authorizes the app, used solely to publish videos on their own behalf via the video.publish scope.
  • Basic creator information (via the Query Creator Info endpoint) needed to prepare a valid post — for example allowed posting settings.

No data belonging to TikTok viewers, followers, or any other user is ever requested, read, or stored.

4. Data used to create video content

Video content is built from public, non-personal information only:

  • Public video game release data from the RAWG Video Games Database.
  • Public manga popularity rankings from AniList / MyAnimeList.
  • Text generated locally by a self-hosted language model, and narration generated locally by a self-hosted text-to-speech engine.

5. Storage and security

The developer's TikTok access token is stored only on the developer's own privately-controlled server, with restricted file permissions, and is never transmitted to or shared with any third party.

6. What is never done

  • Data is never sold, rented, or shared with advertisers or other third parties.
  • No data from other TikTok users is collected, even incidentally.
  • No content is published automatically without the developer having reviewed it beforehand.

7. Retention and deletion

The access token is kept only for as long as the tool remains active. It is deleted immediately if the developer revokes the app's authorization from their TikTok account settings, or if the tool is discontinued.

8. Contact

Questions about this policy can be sent to mistergwadadi@gmail.com.
